## 📖 项目简介

**Papers We Love**(简称 *PWL*)是一个围绕计算机科学学术论文的阅读、讨论与学习的社区,在 GitHub 上拥有超过 10 万 Star。它把散落在互联网各处的计算机领域经典论文汇总成一份目录,涵盖分布式系统、数据库、编程语言、操作系统等方向。由于版权限制,仓库本身通常只收录论文的链接(能托管的部分会用 📜 标出),本仓库为其提供中文介绍与导读文档。

## ✨ 主要特性

- 📚 **经典论文目录**:汇集社区公认的最优秀的计算机科学论文,一站式检索
- 🌍 **全球化社区**:遍布各地的线下分会(Chapters)定期举办论文分享聚会
- 🎥 **视频资源**:YouTube 频道提供历年分享会的演讲视频与播放列表
- 💬 **Discord 社区**:在线讨论论文内容与 PWL 相关话题
- 📖 **论文阅读指南**:整理了多篇"如何阅读学术论文"的实用资料
- 🔗 **扩展资源清单**:收录 arXiv、Google Scholar、The Morning Paper 等找论文的好去处
- ⬇️ **批量下载脚本**:一条命令即可抓取并下载目录中的论文 PDF
- 🤝 **开放共建**:欢迎通过 PR 推荐新论文、优化目录组织、补充其他论文仓库

## 🚀 快速开始

1. 访问原项目仓库浏览论文目录:https://github.com/papers-we-love/papers-we-love
2. 按感兴趣的分类(分布式系统、数据库、编程语言、操作系统等)挑选论文,标题旁带 📜 的可直接下载 PDF
3. 克隆仓库到本地:

```bash
git clone https://github.com/papers-we-love/papers-we-love.git
cd papers-we-love
```

4. 一键抓取并下载目录中所有论文 PDF:

```bash
$ ./scripts/download.sh
```

更多下载选项见原仓库 `scripts/README.md`。

5. 想深入讨论?加入官方 [Discord](https://discord.gg/Tu2VynkRWv) 社区,或关注 [YouTube 频道](https://www.youtube.com/user/PapersWeLove)观看演讲视频
6. 想在自己的城市组织分享会,可参考原项目的分会发起指南;参与贡献请阅读其 CONTRIBUTING.md

完整源代码与最新版本请访问原项目:https://github.com/papers-we-love/papers-we-love
